Mihin verkkoanalytiikkaa voisi hyödyntää?

Cloudflare Web Analytics kerää yksityisyyttä kunnioittavaa käyttödataa ilman evästeitä. Seurantaa voi hyödyntää useilla tavoilla. Ensinnäkin se paljastaa, mitkä sivut tai toiminnot kiinnostavat käyttäjiä eniten – esimerkiksi millä pelisessioiden vaiheella pelaajat lopettavat pelin, mikä auttaa parantamaan käyttökokemusta. Toiseksi sivuston latausaikojen ja Core Web Vitals -mittareiden seuranta auttaa tunnistamaan suorituskykyongelmat ennen kuin ne haittaavat käyttäjiä. Kolmanneksi geografisten alueiden ja laitetyyppien analyysi ohjaa mobiilioptimointia ja kieliversioiden priorisointia. Sovelluksen virhekirjauksiin yhdistettynä analytiikka kertoo, missä ympäristöissä bugeja esiintyy eniten.

CORS-ongelman välttäminen

CORS (Cross-Origin Resource Sharing) tulee vastaan, kun selain estää pyynnön toiselle domainille. Yleinen ratkaisu on asettaa palvelimelle oikeat Access-Control-Allow-Origin -otsikot. GitHub Pagesin kanssa staattiset resurssit kannattaa sijoittaa samaan originiin tai käyttää Cloudflaren proxya, joka lisää tarvittavat otsikot automaattisesti. Cloudflare Workers voidaan myös asettaa välityspalvelimeksi, jolloin CORS-otsikot lisätään ennen vastausta selaimelle ilman muutoksia taustajärjestelmään.
